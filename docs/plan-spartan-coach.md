# Plan — 불꽃 스파르타 코치 + 빈도 통계 버그 수정

## 결정된 방향 (사용자 확정)
- **페르소나**: 불꽃 스파르타 코치 — 에너지 폭발, 끌어올림, 챔피언 언어.
  단 안전선은 확실히 (허리/통증 시 즉시 멈춤).
- **멘트 우선순위**: ① 내 기록 반영 개인화 ② 감정/동기 자극.

## 문제 2가지
1. **"주 0.5회" 버그** — 시작일(7/19) 무시하고 세션수를 고정 4주로 나눔.
   → 3일차 유저가 "성장에 부족" 판정 받음.
2. **말투가 딱딱/기계적** — "데이터 기반, 비난 없이, 단호" 톤이 임상적이라
   PT 받는 느낌이 안 남.

## 변경 (3 파일)

### 1. app/api/training-report/route.ts — 빈도 계산 정직하게 + 톤
- `perWeekLast4`: 고정 `/4` 제거. 실제 추적 기간 기준으로 계산.
  - `trackingDays = min(28, 오늘 - firstDate + 1)`
  - `weeks = max(1, trackingDays / 7)` (최소 1주로 바닥 → 초기 과대/과소 방지)
  - `perWeekRecent = round1(sessionsInWindow / weeks)`
  - stats에 `trackingDays` 추가로 넘겨서 모델이 표본이 어린지 알게 함.
- 프롬프트 규칙 보강:
  - `trackingDays < 14`면 빈도 판정 **유보** — "아직 페이스 단정하긴 이름,
    데이터 쌓이는 중"으로. "주 X회 부족" 단정 금지.
  - 어조: 임상적 "단호"에서 **불꽃 스파르타 코치**로. 데이터는 그대로 근거로
    쓰되, 판정을 뜨겁게 전달 (예: "벤치 정체 3주째, 이번엔 +2.5 쥐어짜!").
    안전선/무리한 증량 금지 규칙은 유지.

### 2. app/api/morning-coach/route.ts — systemPrompt 페르소나 교체
- 현재 "짧고 단호하지만 비난하지 않는다" → **불꽃 스파르타 코치**로 재작성.
  - 에너지 폭발, 끌어올리는 어조. "가자", "쥐어짜", "챔피언" 류 허용.
  - **개인화 강제**: 최근 기록/연속 출석/정체 등 실제 관찰된 사실을 반드시
    한 조각 이상 콕 집어 말한다 (예: "저번보다", "3일 연속", "벤치 정체").
    데이터 없으면 지어내지 말고 "오늘이 1일차, 첫 기록 만들자"로.
  - **동기 자극**: go엔 불 붙이는 한 방, no_go엔 죄책감 대신 "회복도 훈련,
    내일 다시 가자"로 끌어올림.
  - 안전선 유지: 날카로운 통증 시 즉시 중단·전문가 안내. 5% 초과 증량·1RM
    실측 금지.
  - 길이: headline 20자 이내, message 2~3문장(에너지 실을 여지), safetyNote
    1문장. (운동 계획 생성 안 함 — 직전 작업 유지.)

### 3. app/morning/page.tsx — 정적 카피 톤 점검 (경량)
- 이미 퀘스트 톤("첫 세트를 쟁취하라")이라 스파르타와 어울림. AI 응답 톤이
  핵심이므로 정적 문구는 어색한 곳만 소폭 손봄 (대규모 변경 X).
